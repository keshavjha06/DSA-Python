# DSA-Python

A collection of Python scripts for learning data structures, algorithms, and core language concepts. Each file is a small, runnable example: one problem or idea, with a function and a short demo at the bottom.

## Requirements

- Python 3

No third-party packages are required. Everything uses the standard library.

## How to run

From the repository root, run any script with Python:

```bash
python3 arrays/two_sum.py
python3 sorting/bubble_sort.py
python3 stack/balanced_string.py
```

Some scripts read input from the terminal (for example recursion and loop problems). Run them the same way and type the values they ask for.

## Topics

| Folder | Scripts | What it covers |
| --- | ---: | --- |
| [`if_else`](if_else) | 12 | Conditionals, relational operators, ternary expressions, and small decision problems (odd/even, FizzBuzz, greatest of three). |
| [`loops`](loops) | 18 | `while` and `for` loops, digit tricks, factorials, factors, series, and arithmetic/geometric progressions. |
| [`patterns`](patterns) | 20 | Nested-loop patterns: stars, numbers, alphabets, triangles, pyramids, diamonds, and hollow shapes. |
| [`functions`](functions) | 9 | Function syntax, arguments, return values, built-ins, and pass-by-object-reference. |
| [`arrays`](arrays) | 35 | Array basics and classic problems: two sum, max subarray, rotate, set matrix zeroes, move zeroes, duplicates, stock buy/sell, and more. |
| [`strings`](strings) | 26 | String basics and methods, palindromes, anagrams, substrings, compression, and character-frequency problems. |
| [`dicts_and_sets`](dicts_and_sets) | 12 | Hash maps and sets: frequency counts, anagrams, two sum, sliding-window substrings, and pair problems. |
| [`builtin_collections`](builtin_collections) | 8 | Built-in containers in practice: `list`, `dict`, `set`, `deque`, queue, and stack helpers. |
| [`sorting`](sorting) | 10 | Bubble, selection, and insertion sort, plus problems that use a sorted array (kth smallest, union, two sum). |
| [`binary_search`](binary_search) | 1 | Iterative binary search on a sorted array. |
| [`recursion`](recursion) | 6 | Recursive factorial, Fibonacci, power, digit sum, palindrome, and printing natural numbers. |
| [`stack`](stack) | 6 | Stack operations, balanced brackets, min element, reverse, and sort using a stack. |
| [`linked_list`](linked_list) | 3 | Singly linked list: node structure, insertion, display, and related exercises. |
| [`oops`](oops) | 20 | Classes, constructors, `self`, inheritance, `super`, polymorphism, abstraction, and small class designs (fraction, complex number, dynamic array). |
